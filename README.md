# 📌 Project: E-Commerce Customer Churn Analysis (SQL-Based Analysis)
Tools Used: SQL (Joins, CTEs, Window Functions, Aggregations), Excel (for results display)

🚀 Description:
Performed churn analysis on e-commerce customer data using SQL to find patterns in customer behavior and identify why users stop buying 🛍️📉. Focused on building queries to extract, analyze, and summarize key churn indicators from a structured database.

🧠 What I Did:

Wrote complex SQL queries to filter churned vs. active users using conditions like last order date and order frequency 📅

Used JOINs, CTEs, and window functions to calculate average order value, order hike %, and satisfaction score 📊

Identified top churn reasons like low engagement, complaints, or fewer orders

Exported query results into Excel for further reporting and visualization 📤

💥 Impact:
Helped understand churn behavior through SQL logic and revealed data-driven ways to improve customer retention and engagement 🔁✨.
